# Beespoke Multilingual SEO Standard

This standard applies to every new landing page and SEO page.

## Supported languages

- English (`en`) at the existing unprefixed URL
- Spanish (`es`) under `/es/`
- Catalan (`ca`) under `/ca/`
- French (`fr`) under `/fr/`

## Publishing requirements

1. Publish a complete localized page for every supported language. Never expose a partially translated page.
2. Keep a self-referencing canonical on every language URL.
3. Add reciprocal `hreflang` links for `en`, `es`, `ca`, `fr`, plus `x-default` pointing to English.
4. Localize titles, descriptions, headings, body copy, CTAs, navigation, interactive tools, schema and internal links.
5. Preserve names, brands, URLs, product names, company names and agreed commercial facts exactly.
6. Keep one stable language selector on desktop, tablet and mobile.
7. Use device/browser language only to suggest an available translation. Never force an SEO redirect or override a visitor's explicit choice.
8. Add every localized URL to the XML sitemap.
9. Run English SEO QA, localized SEO QA and SERP-readiness QA before publication.
10. Review search performance by country, query and page in Google Search Console; improve each locale independently.

## Translation quality

Translations must preserve meaning and commercial claims, use natural B2B terminology for the target market, and keep the Beespoke voice direct and specific. Translation catalogs are stored with the site so builds remain deterministic and reviewable. Machine-generated drafts are not publishable until terminology, proper nouns, metadata and buyer-facing copy pass the localized QA and editorial review.
