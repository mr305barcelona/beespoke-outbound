# Beespoke Outbound Lead Generation

This repository contains the public website for [Beespoke Outbound Lead Generation](https://outbound-lead-generation.com/), a founder-led B2B outbound and appointment-setting consultancy based in Barcelona and serving clients internationally.

Beespoke helps B2B companies define target accounts, develop credible outreach, manage LinkedIn conversations, and book qualified sales meetings.
